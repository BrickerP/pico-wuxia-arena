# Demo 实现与验收清单

## 当前交付状态

主题为中式写实PVE刀术短竞技场，手感优先、视觉其次，终端为Space Pro／OS6，技术栈为Kotlin + PICO Spatial SDK6.1.9。本轮按用户要求扩充可用人物、场景、UI、动作与特效，仍围绕同一酒馆院落和三轮试炼。

以下勾选表示资产和代码已接入。主控已完成包含玄甲头部修订模型的整合版编译打包。本轮没有运行游戏自测、测试套件、模拟器或真机验收。

## 已实现的游戏路径

- [x] 准备、三秒倒计时、三轮交战、清场补给、胜利／死亡／超时结算和重新挑战。
- [x] 玩家生命、体力、气势、连击、分数和本机最佳成绩。
- [x] 同一姿态判定器产生挥刀／前刺命中、格挡、弹反、身法闪避与双手蓄推结果。

- [x] 暂停、显式恢复、重开及追踪失效撤销旧动作上下文。
- [x] 桌面按键和五个预演按钮生成头手轨迹，设备模式使用实际SDK观察。

## Review修正

- 用有符号步态位移消除前后步切换的镜像相位跳变，绝对路程继续驱动脚尘。
- 格挡与弹反火星取玩家头前守势代理到玩家刀段的最近点，敌人护身受击使用敌人身体代理。
- 特效仅使用导入的真实节点动画，缺少动画资源时明确禁用该项并记录原因。
- 缩短站立受击过渡，保留斩击接触时标，明确处决的受创与倒地阶段。
- 角色、动画与特效按场景生命周期释放，暂停／追踪丢失／重开撤销当前显示与旧反馈。
- 离线展示发现玄甲源模型的颅顶与束发缺损，已重生成并发布更新。
