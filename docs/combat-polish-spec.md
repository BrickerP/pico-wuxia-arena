# 中式竞技场动作与打击反馈制作规格

## 目标与范围

2026-11-10用户指定探索的空间与生活质感参考《骑马与砍杀》《天国拯救》，近身对砍参考《影之刃零》《鬼武者》《只狼》，美术参考《黑神话》。本规格把这些参考转为当前短Demo的制作目标，所有数值为首版调校值。

正式交付为Kotlin + PICO Spatial SDK 6.1.9、Space Pro／OS6、Full Stage。唯一仓库为pico-wuxia-arena。先完成现有酒馆／庭院的一段可观察环境与三轮对砍，再依同一质量标准扩展。人物、刀具、动作、路面、建筑、光照、UI与反馈应在同一段实际玩法中共同验收。

## 推进选择

| 顺序 | 收益 | 代价 |

采用第三种。2026-11-11按用户最新要求扩展为十二路专业制作，Root负责一条正式接入链。近身正劈为第一条完整样板，同时提升人物、服装、建筑、原生光影、特效、声音和UI，接入已有左右方向、格挡、弹反、闪避、技能与处决。具体责任见[并行制作与审核入口](agents/README.md)。

## 当前源码基线与优先缺口

- 普通身体25、头部30基础伤害，速度倍率1至1.4，连击每层加10%，最高5层。三轮敌血100／125／150，玩家100。
- 普通出刀耗精力12，基础恢复14／秒，举刀防守4／秒。连击窗口1.6秒。格挡耗28，弹反窗口180ms，弹反硬直550ms。
- 最新代码562449a中CombatImpact含实际伤害、部位和致命标记，驱动敌人动画、白闪、FX、声音、触觉、接触灯与世界空间跳字。短停与致命死亡时钟已统一，长tick首次正常呈现前的短停丢失和长期FX排队已修。
- 玩家刀光基于实际刀根尖65ms采样，静止与识别器重建时清历史。真实头手继续实时跟踪。
- 世界空间跳字有四槽、600ms／8cm时序与fatal保护，交战控制面板已有紧凑版。109项所选回归通过，端内命中画面与整体美术仍需审核。
- 左右攻击规则和格挡识别存在，旧正式8clip模型的正常循环仍固定上劈与slash源。三角色10clip、三方向新动作和同源profile已生成候选，整合由09与Root推进，turn和防御／卸力继续接线。
- 独立火星／湿布／近地颗粒已有源资产。08负责真实切向与运行发射，04继续资产强化。当前正式粒子还有整组网格运动，人物近景、服装结构、建筑构图和光色整体仍偏粗糙，是新并行任务的重点。
- 模拟器设置已实读Space对应右手A，官方typed动作入口已注册。自动化Host原生Space尚未取得完整callback／轨迹／扣血证据，Root继续负责实际输入验收。

以上为源码事实。端内延迟、真实手感与性能仍需实际画面和真机验证。

## 反馈分层与第一版数值

以毫秒、米、实际伤害和接触材质配置。示例中的帧数与像素转为时间和空间量，显示刷新率变化时保持同一设计时长。

| 接触 | 敌人接触停顿 | 呈现意图 |
| --- | ---: | --- |
| 衣物／身体命中 | 70ms | 短促、清楚、有回弹 |
| 头部要害命中 | 90ms | 更明确的反应和较高音色 |
| 甲片命中 | 85ms | 钝冲击、少量金属火花 |
| 护身吃刀 | 30ms | 防住大部分伤害的硬接触 |
| 玩家格挡 | 35ms | 金属交击与持刀触觉 |
| 玩家弹反 | 95ms | 最清晰的刀刃交击、破势回弹 |
| 技能命中 | 100ms | 范围受控的气流／衣尘反应 |
| 敌人致命击／处决 | 150ms | 接触保持后进入受控慢动作 |
| 玩家受击 | 0ms | 保留应急操作与真实头手跟踪 |

真实HMD、真实双手与玩家刀持续跟踪。接触停顿作用于敌人动作、敌人接触姿态和与之相符的反冲表现。玩家持刀阻力通过手柄触觉、声音、接触高光与小幅刀身视觉反应表达。比赛时间与资源时钟保留明确的现实时间语义。

摄像机继续由真实头部控制，局部振动由游戏物体承担。此选择参考Meta官方关于避免游戏事件引起失控视点震动的VR设计说明，PICO端实际舒适性仍需Space Pro验收。[VR视点设计依据](https://developers.meta.com/vr/resources/publish-content-consider/)

### 闪光与局部震动

- 先试敌人身体象牙白命中闪28ms，致命40ms，闪后立即恢复原PBR层次。材质必须为角色实例独占，恢复时使用原值，暂停／重开／换轮清理。
- 短停期间显示接触星芒，冷暖接触灯常规60ms、要害75ms、弹反90ms、致命100ms。弹反核心约90ms，常规金属星芒约65ms。
- 视点继续由真实头部驱动。短振集中在刀身与受击部位，初试2至4mm、60至90ms衰减，配合现有触觉。任何全屏反馈保持低遮挡。

### 反冲、粒子与刀痕

- 现有根反冲为约2.5至8cm、220ms往返，模型和接触代理共享。首批保留该一致性，后续按姿态图调曲线。技能现有35cm实际推退单列处理。
- 湿衣物接触试6至10颗水滴／纤维碎屑，约2至4mm颗粒、180至320ms寿命，运动方向来自切向与接触法线。
- 金属接触试8至14条短火星，少量星状核心，避免覆盖敌人准备动作。落石／地面火星须由真实材质接触触发。
- 瞬时核心留在真实接触点。长时间伤痕需要可靠目标局部附着，首批缩短原悬浮scar包络，随后按实际骨骼或表面附着完善。
- FX槽位满时按当前事件优先级与可用预算取舍，致命／弹反优先。已过期接触不排队重放，完整伤害事件仍供声音、触觉、UI独立消费。

### 斩击轨迹与伤害数字

- 轨迹使用实际刀根／刀尖采样，保留约50至70ms历史，形成薄而半透明的弧面。待机与缓慢举刀时收敛消失，跟踪中断立即清空。旧孤立blade_arc资源应接成此单一路径或移除。
- 跳字读取同次EnemyDamaged的appliedDamage，格挡零伤不生成伤害数字，护身显示真实削减值。
- 数字在接触附近稳定深度出现，上浮约6至10cm、寿命550至650ms，轻微弹起后淡出。要害命中只做小幅字号与暖金区别。
- 常规数字保持清楚可读，消失阶段可用一次短亮度收束替代反复闪烁。与敌人脸、刀路和关键提示避让。

### 致命时序

同一物理接触携带实际伤害、部位和fatal。敌血由正数扣到0时，普通斩和处决均走150ms短停。之后死亡视觉时钟以0.35倍推进220ms，再用180ms平滑恢复到1倍。头手、UI交互和系统跟踪保持实时，场景使用同一受控死亡时间推进相关动作。换轮等待应允许fall动画和落地效果完成。

要害与致命元数据同时进入声音、触觉、灯与FX。保留接触材质的音色来源，要害试1.12倍播放速度、1.12倍效果尺寸，致命试0.90倍播放速度、1.30倍效果尺寸与80ms触觉。较低剩余血量的致命击也应得到明确的结束重音。

## 动作制作

1. 人物站立有明确重心、自然呼吸、放松空手和稳定持刀，脚底与地面吻合。
2. 正劈含守势、引刀、接触、随势、回守，腰胯带动肩肘腕，刃向、刀尖轨迹、接触点与命中代理共用来源。先修战斗站姿，再做连续曲线。
3. 完成正劈样板后制作左右斩。已有方向规则、动画选择和接触代理一并接通，再安排可读的方向序列。
4. 防御与弹反分开表现。防御保留支撑，弹反有刀刃偏转、手臂卸力与敌人破势。闪避靠实际头手位移识别，反馈集中在掠过风声、近地尘与短暂成功提示。
5. 行走／转身按步态相位控制脚底，起步、停步、回守应连续。脚滑测量必须结合实际足底图，单纯骨关节位移不能替代地面接触。
6. 受击与处决维护原有角色身份和刀长。衣物、手腕、头颈与刀面在完整过渡中检查，关键姿态通过后仍需检查补间。

## 人物、刀具与环境

- 人物沿当前成年中式刀客精修，优先领襟连续折边、袖口退腕、手指与握柄、脸部与发际线。Tripo CLI使用ov与显式tripo-v3.1，来源和派生补丁保持可追溯。
- 刀具继续现有dao，打磨刀脊／刃口分工、护手厚度、握柄缠绕、接触磨损和金属反射，米制尺寸与握点随动作共同验收。
- 以现有酒馆／庭院形成雨后中式场景。石路高低、砖缝、排水方向、低处积水、木柱基座、门槛和瓦檐都有结构原因。积水和湿润集中在合理位置，木材与石材保持粗糙度差异。
- 灯笼暖光与阴雨冷环境共同塑形，脸、刀刃和出招手臂是战斗阅读重点。接地阴影与环境光先取得稳定实图，再依真机预算加细节。
- 探索部分先以现有短场景的步行观察、建筑尺度、声源和少量生活痕迹建立空间感。战斗边界、站立区域和视线保持清楚。

## UI与数值调校

UI按准备／交战／换轮／结算组织。交战优先显示敌人身份与血量、玩家生命／精力／气，以及即时命中／弹反结果。操作说明集中于准备阶段，战斗中避免长段文字。采用中文可读字号、清楚的对比与稳定空间深度。

首批保持现有伤害、资源、动作识别与弹反窗口，只统一反馈事件和时间。数值在动作／命中反馈可见一致后按以下顺序调。

| 项目 | 当前基线 | 后续判断标准 |
| --- | --- | --- |
| 普通／要害 | 25／30，乘速度和连击倍率 | 每次有效接触伤害有解释，同一挥击只扣一次 |
| 敌血 | 100／125／150 | 三轮逐步加压，单轮目标约15至30秒交锋 |
| 出刀／格挡精力 | 12／28 | 连续乱挥有代价，正确防守能恢复节奏 |
| 弹反 | 180ms，敌硬直550ms | 提示、真实刀路与反击空档相符 |
| 连击 | 1.6秒，最高5层 | 相邻有效出刀形成节奏，暂停或中断无意外续接 |
| 要害反馈 | 头部命中确定触发 | 暴击感来自确定的部位与破势时机 |
| 技能／处决 | 55伤害；敌血≤max(25,初血1/4)可处决 | 动作意图清楚，资源与执行提示一致 |

## 验收与bench

以同机位、同距离、同姿态、同一招制作前后图／短片，查看脸、手、刀柄、领襟、脚底、命中点和反馈时序。记录输入到接触、接触到首个可见／可听／触觉反馈的时间，不能用导入成功代替呈现。

一次成功必须是实际动作进入共享判定，产生一次正确伤害，动画与代理同步，FX／声音／触觉／UI使用同一接触身份，收势后继续交锋。真实桌面键进入模拟器的证明、完整三轮流程与Space Pro性能仍单列待验收。

专项数值与时序测试覆盖正常、致命、无伤、重复／批量、长tick、暂停／重开和换轮。游戏整局自玩继续按用户要求后置。真机画质、舒适性与帧时间以Space Pro实测为准。
