## 验收与边界

- 快乐路径：一次来袭攻击可被格挡或弹反，弹反后能反击，战斗可结束并重开。
- 边界至少覆盖：提前静止持刀只算普通格挡；错误时机不算弹反；快速挥刀不会跳过接触；一次挥击不会重复伤害；没有移出攻击范围不能凭闪避动作获得无敌；追踪丢失不能误判攻击或受伤。
- 保留可供 QA 重放的敌人招式与事件结果。跨平台物理不要求逐帧完全一致，要求结果和时间误差符合约定。

### 敌人状态与转移

正常链路：**待机 → 预备 → 出招 → 生效 → 恢复 → 待机**；有效受击或弹反打断当前招式进入**受击**，生命归零进入不可自动退出的**死亡**。受击用普通受击和弹反硬直两种表现，不增加另一套 AI 状态。

| 状态 | 进入与行为 | 退出与边界 |
| --- | --- | --- |
| 待机 | 面向玩家，等待至少 0.8 秒；水平距离不大于 1.6 米时，从左、右、上三招中选择一招。距离从敌人根节点到头部水平位置测量，数值待场景尺度确认。 | 超距或追踪无效不选招；测试可指定招式，正式选择需记录随机种子和实际招式。 |
| 预备 | 明确展示来袭方向；持续时间见下表。 | 结束时锁定目标位置和攻击方向，随后不追踪玩家位置；玩家提前离开后仍按已锁定方向出招。 |
| 出招 | 刀刃向锁定方向运动，但不产生敌方攻击伤害。 | 到达生效起点进入生效；受击或死亡可打断。 |
| 生效 | 仅在生效时间段内依据刀刃连续扫掠裁定防守或受伤；一个敌方招式最多产生一个防守或伤害结果。 | 未接触则结束为未命中；普通格挡后进入恢复，弹反后进入受击硬直，命中后进入恢复。 |
| 恢复 | 收刀并恢复到待机姿态，不产生敌方攻击伤害。 | 计时结束回待机；有效玩家挥击可打断。 |
| 受击 | 非致命挥击播放受击；被弹反播放硬直。初始时长分别为 0.3 秒、0.55 秒。 | 硬直中仍可被新的有效挥击反击；非致命反击重新进入普通受击，生命归零转死亡。 |
| 死亡 | 停止攻击和受击判定，播放死亡动作并保留战斗结果。 | 只由重开流程重置；重开须同时清除双方生命、计时、招式/挥击去重和轨迹历史。 |

有效玩家挥击在预备、出招、生效、恢复和受击时均可命中敌人。按实际接触时间处理同一时间步的事件；时间相同时依次处理双刀防守、玩家挥击命中、敌刀命中玩家。先发生的受击或死亡立即取消尚未发生的敌方接触，避免一次跨帧出现被打断后仍出伤害。普通格挡或命中提前结束生效时，从恢复阶段起点同步动作与计时。

灰盒初始数值建议：双方各 100 生命，玩家有效挥击造成 25 点伤害，敌人命中造成 20 点伤害，生命不低于 0。敌人归零判胜，玩家归零判负并停止后续出招与伤害；结果通过战斗层提供给主控的胜负与重开入口，具体入口待工程基线确认。

### 接触与结果规则草案

1. **统一接触：** 对相邻有效采样间的玩家刀刃和敌人刀刃做连续扫掠，并将时间段裁切到敌方生效窗口；不得只看当前帧的位置。比较刀刃与刀刃、敌刃与玩家受击区域的最早接触时间，同一时刻接触优先处理刀刃防守；此前已发生的受伤不被之后的格挡追认。大步长跨过整个生效窗口也须检查窗口内轨迹。未采到的高速曲线路径无法凭端点精确恢复，需与主控约定采样间隔、异常间隔处理、扫掠精度和误差，再用 Unity 验证。
2. **格挡与弹反：** 生效窗口内双刀接触即普通格挡；若接触时间落在生效开始后的 `[0, 0.12)` 秒内，且玩家刀刃在接触前 0.10 秒中朝敌刀主动移动至少 0.08 米，则提案判为弹反。移动方向以该时间段起点两刀最近点的连线为准，只计算玩家刀刃对应点的位移投影；起点已相交或有效样本不足时只算普通格挡。不能把敌刀靠近算作玩家动作；提前静止持刀、晚接触或移动方向错误均不算弹反。阈值及几何算法需用合成轨迹和实机试玩调整。
3. **玩家伤害与反击：** 仅连续有效挥击的刀刃接触敌人受击区域才造成伤害；按「挥击标识 + 目标」去重，一次挥击不能因多段轨迹或多个碰撞体重复伤害。桌面按键只能产生虚拟头手轨迹，不能直接调用命中、格挡或弹反成功。
4. **闪避与玩家受伤：** 敌人锁定方向后，玩家头部实际离开刀刃扫掠区域即可避开；没有离开则不能因闪避动作获得无敌。灰盒建议先以头部位置为球形受击代理，半径 0.15 米；它不代表已识别躯干或腿部，是否需要其他受击区域由主控确认。没有接触即可记录未命中，不把所有未命中都标成成功闪避。
5. **追踪中断：** 头部位置或持刀手的位置、方向无效时立即暂停战斗计时和伤害裁决，不跨无效区间连接刀刃轨迹。恢复后须取得连续有效采样，且持刀手动作识别重新就绪，才丢弃中断前的招式与挥击、让敌人回待机并重新等待出招；不得在恢复瞬间把位置跳变当作挥刀，也不得强制移动玩家头部或手部。暂停、换手、重新居中和缓冲缺口同样是轨迹不连续点，不能跨越它们求速度或接触。
