## 验收与边界

- 快乐路径：一次来袭攻击可被格挡或弹反，弹反后能反击，战斗可结束并重开。
- 边界至少覆盖：提前静止持刀只算普通格挡；错误时机不算弹反；快速挥刀不会跳过接触；一次挥击不会重复伤害；没有移出攻击范围不能凭闪避动作获得无敌；追踪丢失不能误判攻击或受伤。
- 保留可供 QA 重放的敌人招式与事件结果。跨平台物理不要求逐帧完全一致，要求结果和时间误差符合约定。
- 没有 PICO 真机时，不能声称真实 VR 识别、手感、舒适度或性能已经通过。

### 1. 连续受击与防连控

**建议规则：**

1. 玩家刀刃的连续有效挥击必须实际扫掠接触敌人受击区域才造成伤害，并按「挥击标识 + 敌人」去重。第一次非致命命中造成 25 点伤害并进入 0.30 秒普通受击；如命中时敌人正处于弹反硬直，则普通受击的结束时间取「本次命中时间 + 0.30 秒」和「原弹反硬直结束时间」中较晚者，不缩短弹反奖励。
2. 上述普通受击尚未结束时，第二个**不同挥击**有效命中，立即开始护刀表现，该击和护刀期间后续每次独立有效命中各造成 10 点伤害；不刷新原受击结束时间，不中断之后的反击。重复接触或同一挥击的其他碰撞体既不再次扣血，也不触发护刀。
3. 原受击结束后，如玩家追踪有效且在待机出招距离内，敌人立即从现有左、右、上三招中选择一招进入预备，跳过普通待机的 0.8 秒等待；仍使用该招完整可见预备、出招和生效时间。若不满足出招条件，则结束护刀并回待机。战斗暂停时不推进计时；失效恢复按输入语义取消旧招及护刀。
4. 护刀持续到该次反击的生效阶段结束或普通格挡／命中使该阶段提前结束；敌人被弹反、生命归零或对局结束时也立即结束。反击可正常被格挡、弹反或闪开；被弹反时进入 0.55 秒弹反硬直，玩家下一次有效反击仍按首次普通命中计算。
5. 每次护刀受击都保留实际扣血、接触与受击反馈。敌人明确呈现架刀护身与蓄势反击，受到护刀击中时只做不破坏出招方向和时序的局部反应；不同反馈事件可供主控接音效和触觉。**生命归零始终立即死亡**，不存在隐形无敌或最低生命保护。

### 2. 待机受击与最小状态

正常链路为 **待机 → 预备 → 出招 → 生效 → 恢复 → 待机**。待机、预备、出招、生效、恢复及受击均可被有效玩家挥击命中；通常进入受击，但护刀期间的命中按上节规则不打断。死亡是终态，仅由重开重置。

| 状态 | 行为和退出 |
| --- | --- |
| 待机 | 面向玩家，通常等待至少 0.8 秒，玩家头部到敌人根节点的水平距离不大于 1.6 米时选择三方向招式；待机时同样可被有效挥击命中并进入普通受击或死亡。 |
| 预备 | 明确展示攻击方向；结束时锁定玩家目标位置和方向，不再自动追踪玩家。普通受击或死亡可打断；护刀反击中的普通挥击不能打断，但仍扣血。 |
| 出招 | 刀向锁定方向运动，未进入生效前不产生敌刀伤害；打断规则同预备。 |
| 生效 | 刀刃只在生效区间内产生敌方接触结果；一招最多产生一次格挡、弹反或玩家受伤。普通格挡或命中提前转恢复；弹反转受击；无接触则窗口结束转恢复。 |
| 恢复 | 收刀且无敌方攻击伤害；可被有效挥击打断，结束后回待机。 |
| 受击 | 普通受击初值 0.30 秒、弹反硬直 0.55 秒；普通受击中的第二个独立有效命中可触发护刀，结束后按上节尝试反击。 |
| 死亡 | 停止攻击及后续伤害，呈现死亡和胜负；重开清除生命、计时、护刀、招式和挥击去重及轨迹历史。 |

按实际接触时间顺序处理事件；同一时刻依次处理双刀防守、玩家挥击命中、敌刀命中玩家；多个同刻玩家挥击按输入序号排序并先按挥击标识去重。普通受击、弹反或死亡取消尚未发生的敌方接触；护刀命中不取消反击，死亡始终取消。普通格挡或命中提前结束生效时，从恢复阶段起点同步动画与计时。双方初始各 100 生命，敌刀命中玩家为 20 点，生命不低于 0；玩家生命归零判负并停止后续出招和伤害。

**与 QA Q06/Q07 对齐：** 敌人由正常测试入口保持待机、无正在执行的招式，生命至少为两次普通伤害；只有真实有效挥击和刀刃扫掠命中才会从待机扣 25 点并进入受击。Q06 必须先独立确认相邻采样两端不重叠、扫掠体相交；Q07 必须确认挥击结束前的持续重叠与同一标识只扣一次。受击动画可能移动目标，实际身体碰撞体、武器尺寸与目标位置需校准，无法证明几何前置时记为阻塞；测试不得直接注入命中或伤害。两例各只有一次有效挥击，不触发二连击护刀。

### 3. 招式与接触驱动的弹反

攻击方向以面对敌人的玩家视角描述。以下时间相对于招式预备开始，秒为单位，区间左闭右开；仍是待测试的初值。

左斩从玩家左侧向右横扫，右斩从玩家右侧向左横扫，上劈从上向下；预备姿态须让三种方向可辨，灰盒不依赖角色根运动移动敌人。

| 招式 | 预备 | 出招 | 生效 | 恢复 |
| --- | --- | --- | --- | --- |
| 左侧横斩 | [0, 0.55) | [0.55, 0.73) | [0.73, 0.93) | [0.93, 1.53) |
| 右侧横斩 | [0, 0.55) | [0.55, 0.73) | [0.73, 0.93) | [0.93, 1.53) |
| 上方劈斩 | [0, 0.65) | [0.65, 0.90) | [0.90, 1.10) | [1.10, 1.75) |

- **接触与时机：** 比较真实刀刃连续扫掠与玩家受击代理的最早接触时间。敌刀整个生效区间内的任意时刻发生双刀接触，都有同等机会触发弹反；不再以生效开始后的前 0.12 秒作为额外门槛。普通格挡和弹反都必须有实际双刀接触；玩家已先受伤或该招已结束，不能事后追认防守。
- **闪避与桌面入口：** 敌人锁定方向后，以实际头部受击代理和敌刀扫掠是否相交裁定受伤；未移出范围不能因做了闪避动作获得无敌，不把所有未命中都标记为成功闪避。灰盒头部球体不代表已识别躯干或腿部。桌面按键只生成可失手的头手轨迹，不直接调用命中、格挡或弹反成功；不强制移动玩家头部或手部。
- **主动迎刀：** 在接触时刻前连续有效的 0.10 秒内，取起点双刀最近点的连线方向和玩家刀身上对应的固定局部点；该玩家点自身位移在此方向上的投影不小于 0.08 米，才判弹反。接触历史不足、起点已相交或方向不可定义时，若当前接触有效则只判普通格挡。位移来自玩家刀刃而非敌刀靠近；提早做完动作后静止、方向相反或投影不足只算普通格挡。
- **无效数据：** 头部位置或持刀手位置／方向无效时暂停战斗，不报告格挡、弹反或受伤；不能跨失效、重新居中、暂停、换手、重开或缓冲缺口推算运动。恢复须连续有效且挥刀识别就绪，再取消中断前的招式与挥击并回待机。
- **精度限制：** 连续扫掠必须裁切到生效区间，即使时间步跨过整个区间也要检查；端点无法精确重建未采到的高速曲线。采样上限、异常间隔处理、几何与时间误差均待主控和 QA 基于 Unity 测试确定；最近点不唯一时需确定可复现的选点规则，不能把本例当成完整碰撞夹具。

### 4. 对外可观察反馈

以下是事件**语义建议，不是已冻结 API 或已实现的音效、动画、触觉**。每项应携带有序事件号、战斗模拟时间、对局标识及相应攻击／挥击标识；涉及输入时关联输入序号和观测时间，供 QA 核对双时钟。重开生成新的对局标识，避免上一局的迟到事件混入。

| 可观察事件 | 产生条件与接入用途 |
| --- | --- |
| 挥击候选开始、结束、取消 | 来自输入侧的有效挥击候选及其连续标识；可驱动挥刀表现，不代表命中。失效或缺口需报告取消。 |
| 敌人招式与阶段变化 | 选招、预备、出招、生效、恢复及被打断；带方向和攻击标识，驱动预警动作并记录时序。 |
| 格挡、弹反、玩家受敌击、未命中 | 敌方一次攻击的互斥结果；记录实际接触时间和位置或未命中原因。静态挡与主动弹反产生不同事件，供画面、音效及手柄触觉接入。 |
| 普通受击、护刀开始／护刀受击／护刀结束 | 标出受击原因、持续时间、护刀起止原因与关联挥击；护刀受击必须同时有实际伤害事件，但不能重置出招计时。 |
| 伤害与生命变化 | 真实目标、来源标识、原始及实际伤害、扣血前后生命；一次有效挥击最多一次，不因多个碰撞体重复发出。 |
| 胜负、重开 | 生命归零先产生伤害与对应死亡／胜负结果；重开清除旧状态后再发出新局开始／重开完成，允许 QA 核对双方初始生命与无旧事件。 |

同一时刻按上述碰撞优先级确定结果，再产生相应伤害、受击表现或胜负事件；不能因为播放反馈再次扣血。同一次敌刀攻击的格挡、弹反、玩家受击与未命中只能有一个最终结果；中断或追踪失效的攻击记录取消原因，不伪装成未命中。
