# 当前目标：雨夜庭院刀客对决

在已有雨夜庭院，用一把刀打一场可重玩的原生 PVE 对决。保留三名顺序对手和原有数值。手感第一：玩家能从对方的肩、腕和刀锋读出来招，看清双刀在何处相接，并在对手收势时还击。

1. 从现有 Full Stage 的「开始试炼」进入，PICO Emulator 的虚拟手柄与头显走同一套头手动作判定。
2. 接刀时显示、接触和卸力使用同一握点。已交付的玩家刀为七个半径 6 mm 的胶囊，全部 5533 个 Steel 顶点的最大外侧距离为 0.416 mm。保留 220 ms 强制回守、不拖手和一次重叠不重复结算。
3. 重点修接触后的过渡：首次截断出招应从实际接触姿势收回，收势中再次碰刀不能让敌人跳帧或无限重置。
4. 在同一 APK 录下真实输入、攻防、结算和重开。输后重开可以证明失败分支；只在三名对手都被打败时记录通关。用同一场景、来招和机位比较修复前后。可见接点、收刀连续性与手感评分各自验收。

本轮只改与这场对决直接相关的阻塞。保留原生 Kotlin + PICO Spatial SDK 6.1.9、单一仓库及正式资产；不恢复十二路派工、不做网页预演。Space Pro / OS 6 上的舒适度、触觉和运行性能另验。当前证据见 [验收清单](../acceptance.md)。
