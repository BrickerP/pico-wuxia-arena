## 制作与合入合同

技术栈只使用Kotlin + PICO Spatial SDK 6.1.9，设备Space Pro／OS 6，Full Stage。保持单院落短竞技场范围，集中完善人物、武器、动作、打击、UI与场景品质。

Root独占公共正式角色producer与manifest的最终发布、library/app资源发布、Main/HomeStage最终接线、共享构建、设备、截图录制和Git。各路只改责任目录或明确授权文件，保留同仓库其他人的编辑；禁止复制仓库、建worktree或另开同链路。Root可将公共producer的具体修改委派内部agent，但正式发布仍由Root处理。

每路在自己的交接文档写交付、来源SHA、可见变化、接入合同、限制与下一项。Root将review和续派写回对应文档；阶段完成后继续已授权队列，不无限等待其他会话，不用离线图、单元测试或导入成功替代设备操作验收。
