# 当前目标

成品 Demo 未完成。唯一产品是雨夜庭院、一把刀、三名顺序对手。手感先于外观。

Codex 上一阶段的失败是把十二路美术合同当成目标：包在换，三轮胜利停在 2026-11-13 的 v9，Boss 重叠时刀可以停住。那些交接文件已经从这条目录删除。不要恢复它们，不要再写下一轮审核表。

## 已经落地

不可证的钢交叠不再永久顶住。

- 解析卸力仍然优先，玩家手不吃敌人的强制位移。
- 卸力证不出来、卸力途中再次接触、或接触查询连续不可证，都进入同一次强制回守。
- 回守最长 `220ms`，敌人沿水平反法线以 `0.65 m/s` 离开，然后 `releaseWeaponHold()` 把刀交还原始跟踪。
- 同一次重叠保持 latch，不能连打出伤。新的合格挥击或新的攻击才解除。
- 实现在 `ArenaSession` 与 `PlayerCombatResolver.releaseWeaponHold()`。

这不是刀刃网格接触，也不是三轮通关证明。

## 只做这两步

1. **一把刀，一个形状。** 用正式 dao 网格派生分段接触体，替换玩家刀上的 12mm 单胶囊。显示、CCD、恢复读同一份形状。现况是 5533 个钢顶点里 4469 个落在胶囊外，最大离轴约 57mm。胶囊单测通过不能当成没穿刀。不要用放大胶囊把洞盖上。
2. **同一个 APK 打完三轮并重开。** 准备 → 倒计时 → 三名敌人 → 胜利或失败 → Retry → 再开。录像、日志、APK SHA 必须是这一包。旧的 v9、7abefa5、手部截图都不能算。

第 2 步通过之前，停止：新手部、衣片、60k、Tripo、IBL、灯笼、场景合批、HUD 改版、Web 握持测试、弹反手感打磨、头闪、技能、处决。这些机制留在代码里，不在当前门里。

- 不要升级 SDK、Gradle、依赖。
