1. 建立站立近景、引刀／接触／回守、弹反、防御／闪避、庭院探索、交战UI六组对照。原项目实际图和新候选同视距、同尺度评审，参考作品只作为其相应品质维度。
2. 分辨人物骨相／轮廓、材质像素密度、服装结构、刀路／身体带动、脚底与接触、特效层次／时序、建筑尺度、光色纵深和UI阅读。每项给具体画面问题与下一步修法。

4. 每轮给Root不超过5个最高影响问题，写对应文件／画面／普通游戏视距和哪个负责人应修。明确接受、返修和未验证，避免所有维度都泛称不够精致。
5. 性能与VR舒适性只报告有来源和实际证据的结论。模拟器与Space Pro证据分开。先做离线资产／设计审核，实际流程由Root统一安排。
