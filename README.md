# PICO Wuxia Arena

面向 PICO Space Pro／OS 6 的中式 PvE 刀术竞技场 Demo，采用 Kotlin + PICO Spatial SDK 6.1.9。体验围绕酒馆院落、一把刀与三名依次上场的刀客展开，单次试炼连续三轮，共用180秒战斗时限。

本轮已补齐游戏链路的代码实现。主控已完成 `:app:assembleDebug --offline` 编译打包，按用户要求，本轮未运行自测、测试套件、模拟器操作或真机验收。运行完成度与手感仍需后续验收，详见[验收清单](docs/acceptance.md)。

## 产品立场与主题

参赛目标是能在Space Pro／OS 6终端运行的中式写实PVE刀术短竞技场。玩家在酒馆院落与刀客近身攻防，核心记忆点是挥刀命中的确定感、迎刀弹反、身法避招与顺畅的反击收势。手感优先，视觉其次，制作范围围绕个人4–8周可打磨的单院落、单刀和三名顺序对手收敛。本轮按用户的资产扩充要求增加角色外观，三轮沿用同一套攻防规则。

| 既定参照与目标 | 本项目对应的交付要求 |
| --- | --- |
| Blade & Sorcery | 刀、头和双手的实际轨迹参与接触与防御，动作意图和命中反馈对应 |
| 荣耀战魂 | 读招、格挡、弹反、闪避、反击、技能衔接与处决形成可读的攻防节奏 |
| 黑神话悟空、影之刃零 | 写实人体比例、交领束带与刀具细节，木作、灯笼、湿石材和冷暖光构成中式空间 |
| 简短精美Demo | 在同一院落打磨角色近景、握点、步法、受击与收刀衔接，优先处理影响战斗观感的缺口 |

三轮与180秒是当前Demo的节奏实现参数，最终体验以攻防确定感、动作流畅度和近景品质评审。本轮接入距离驱动步法、站立受击与两段处决衔接，足底接触、握点和过渡质量继续参与最终完成度评审。功能接通、编译结果和运行验收分别记录。

应用显示名为“酒馆试炼”。正常VR界面优先显示试炼目标、资源、实际来势与反馈，输入来源在桌面预演和追踪异常时显示，得分与最佳成绩集中于结算页。

## 游戏流程

准备就绪 → 开始 → 三秒倒计时 → 第一轮交战 → 清场与补给 → 下一轮倒计时 → 三轮胜利结算，或玩家生命归零／战斗时限耗尽后失败结算。结束后可重新挑战。

- 敌人逐轮为100、125、150生命，待机出招间隔逐轮缩短。AI会在待机阶段接近玩家，并保持近身距离。
- 玩家挥刀与前刺由真实刀段、移动速度和扫掠轨迹产生命中，区分头部与躯干，同一挥击去重。
- 举刀形成格挡，近期快速迎刀可产生弹反，侧移、后撤和下蹲用于避开攻击。持续守势消耗体力，体力不足会破防。
- 连击窗口影响伤害与得分。命中、防御和闪避积累气势，双手收刀蓄力后前推可释放破势。
- 同一“破势 / 处决”入口在敌人低血时自动进入处决分支。敌人表现为头部受创后倒地的两段过渡，玩家手部继续随实际追踪动作。
- 玩家生命、体力、气势、轮次、倒计时、得分和结算进入HUD，最佳分数保存在本机。

## 输入与桌面预演

设备模式使用PICO头部及控制器观察。格挡、弹反、闪避、攻击和双手技能均由姿态产生结果。

桌面预演仅在debug模拟器条件下启用。键盘和五个预演动作按钮生成连续的虚拟头手轨迹，经过与设备模式相同的输入队列和战斗判定。按键与按钮不会直接扣血。

| 键位 | 预演动作 |
| --- | --- |
| 1 / J | 斩击 |
| 2、3 | 左斩、右斩 |
| 4 / K | 前刺 |
| 5 / V | 头上架刀 |
| 6 / B、7 / N | 左、右架刀 |
| 8 / Z、9 / X | 左、右闪避 |
| C | 下蹲 |
| G | 破势 / 处决，敌人低血时自动处决 |

WASD、Q/E及右键保留模拟器的移动、升降和转向控制。应用内暂停、显式恢复与重新开局走既有生命周期控制和输入队列。

## 人物与精细动作

运行目录为 `app/src/main/assets/models/opponents/`，三轮依次选择 `base.glb`、`indigo.glb`、`veteran.glb`，对应试刀客、青衫护院和玄甲守擂。人物由ov区域Tripo CLI通过 `tripo-v3.1` 生成，完成PBR和78骨绑定，统一为约1.78m、+Y向上、朝+Z。每名角色的DAO均刚性蒙皮到R_Hand，与身体共用一个GPU骨架。玄甲守擂已发布头部完整的修订模型，身体25,113三角，DAO为3,722三角。

| 动作资源 | 用途与当前接线 |
| --- | --- |
| idle、walk | 待机与距离驱动的前后步法 |
| hit_body、hit_head、hit_side | 身体受击、头部受击与弹反后仰 |
| slash | 本角色原生斩击，保持2.117秒接触标记 |
| fall | 普通倒地及处决的第二段 |
| turn | 已打包的转身资源，供后续动作编排使用 |

生产管线把41骨动作源的世界空间rest delta重定向到各角色78骨目标，保留目标骨长、蒙皮与逆绑定矩阵。转移动作中的30个指骨使用本角色原生slash在2.117秒的握刀采样姿态。玩家VR输入继续来自实际头手追踪。

步法按有符号累计位移映射到walk源0.333333–1.5秒循环，每1.45m推进一周期，反向移动连续改变相位。普通受击与弹反使用独立站立反应，部位由真实受击事件保存，受击切换为55ms过渡。收势取样到原生slash的3.4秒，保持2.117秒接触标记。处决先播放0.45秒头部受创，再转入倒地，局间为5秒。当前交付包含动作资源与播放接线，足底IK、各体型握点和专用双人配对处决仍属于后续质量工作。

## 场景、UI与特效

酒馆、灯笼和石铺地之外，`courtyard_details.glb`增加茶桌酒具、矮凳、封口酒坛组、双侧挂灯木栏、荷叶石盆和侧铺地。新增六模块共29,378三角，沿用木石与灯笼PBR，并增加陶釉、青瓷、封口布的512px贴图。中央交战区保持净空，运行场景接入冷色主光和两侧暖灯。

四份短促特效共796三角，覆盖金属火星、窄刃光、破势环和脚尘。`CombatEffects`复用各自实体，按真实反馈、刀段与步法定位，播放普通glTF节点动画。缺少相应导入动画时该项记录警告并禁用，加载或SDK创建异常按场景失败清理路径处理。

两块HUD维持400×400dp与500×260dp。revision16补充四条刀术要诀、敌招阶段提示、当前角色名与实际双手蓄力进度，处决、局间和终局提示按状态优先显示。得分与最佳成绩集中于结算。

## 本地构建

配置JDK 21、PICO SDK 6.1与Android SDK，并设置 `JAVA_HOME`、`PICO_HOME`、`ANDROID_HOME`。本机SDK路径留在未纳入版本控制的 `local.properties`。

```bash
./gradlew :app:assembleDebug
```

APK输出为 `app/build/outputs/apk/debug/app-debug.apk`。后续运行验收可使用已准备好的PICO模拟器或Space Pro，应用包名为 `com.example.wuxiaarena.p0d2f0182`，启动Activity为 `.platform.LaunchActivity`。
