# 中式刀战浏览器预演

入口固定为 `prototype/web-v0.18/`。当前代码保留上游v0.32的城堡、谈判、通道/台阶、八名人物、TP入场→FPS、三段速度与养成，并接入正式人物与真实第一人称手刀。PICO原生验收见[总交接](../../docs/agents/README.md)。

## 运行与操作

在仓库根启动：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/prototype/web-v0.18/`。需要联网获取固定版本Three r147、Basis解码器与美术资产。首次三模型合计约114MB，网络较慢时会等待数分钟；资源身份与贴图全部校验成功后进入试炼。

WASD移动；U轻击、J重击、I闪身、K架刀；鼠标/锁定视角、拾取及其它动作依页面提示。K记录按下时的实际持刀侧，松开或暂停会清理状态。浏览器的键盘招式用于预演；原生PICO运行时消费真实SDK头手轨迹并做动作判定。
