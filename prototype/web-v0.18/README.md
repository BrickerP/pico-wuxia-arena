# 酒馆试炼 · 自由手 v0.18（电影化慢镜 + Boss 登场运镜）

浏览器原型切片，`ruleset_id: wuxia-contact-v0.18` / `revision: cine-1`。

## 运行

双击 `index.html`（需联网加载 three.js）。这是 PICO VR 版的动作与演出试验场，先在网页把打击感与镜头语言调顺，再迁到 PICO。

## 操作

- 鼠标移动 = 双手与刀的位置（第一人称，能看到自己的手）
- 走近兵器架，把刀贴到手上即算持握，不需要按键
- 左键 = 挥砍；挥动的方向与速度就是刀路

## 本版做了什么

1. **命中分级的电影化慢镜**：轻 / 中 / 重 / 弹反 / 破势 / 终结六档，每档有独立的降速倍率与时长，切入快、恢复慢的不对称曲线，与既有的反应慢动作取最小值叠加。
2. **Boss 登场三段运镜**：拉远交代战场规模 → 环绕抬升建立压迫 → 推进收窄 FOV 收束到对手，配上下黑边与题字，点击可跳过。
3. **自由手扫掠判定**：用刀身线段对敌方身体轴线做连续检测，命中后走完整伤害结算（伤害、卡肉、破势、慢镜、终结）。
4. **修掉三个导致「打不中」的根因**：自由手坐标轴变量被块内 `const` 遮蔽导致每帧报错中断；开局未装备时敌人与倒计时冻结；`resume()` 清空自由挥刀状态导致伤害结算首行直接返回。

## 已知限制

- 仍然是网页切片，不是 PICO 构建；VR 手柄的抓握与挥砍手感需要在 PICO 侧重新接。
- 敌人 AI 与招架判定沿用 v0.13 的规则骨架，本轮只改演出与命中链路。
