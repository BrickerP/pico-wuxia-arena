# 动作模组接口 v0.19

给负责具体模组的 agent。系统侧已完成：槽位、切换、连段推进、熟练度解锁、处决触发、HUD。你只需要填数据。

## 一、数据结构

```js
const MOVESETS = {
  dao: {
    light: { id:'dao.light', name:'缠头刀', theme:'通背八步十三刀', maxRank:0, segs:[ ... ] },
    heavy: { id:'dao.heavy', name:'倒步劈刀', theme:'八步十三刀 · 劈', maxRank:1, segs:[ ... ] }
  },
  sword:{...}, spear:{...}, staff:{...}
}
```

四把武器的 `id` 固定为 `dao` / `sword` / `spear` / `staff`，与 `Battle.weapons` 一致。

## 二、段（seg）字段

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `n` | string | 是 | 段名，HUD 直接显示 |
| `dmgMul` | number | 是 | 伤害倍率，乘以武器基础 `damage`（刀 13 / 剑 12 / 枪 15 / 棍 10） |
| `prMul` | number | 是 | 压制倍率，乘以武器基础 `pressure`（刀 16 / 剑 14 / 枪 20 / 棍 28） |
| `cine` | string | 否 | 命中时慢镜档位：`light` / `mid` / `heavy` / `break` / `parry` / `finish` |
| `tag` | string | 否 | 语义标签：`cut` / `thrust` / `pierce` / `cleave` / `sweep` / `smash` / `control` / `feint` / `execute` |

判定与结算只读这四个字段。你要做更细的动作曲线（起手/挥出/收势、位移、刀路），在当前版本里由手臂物理与鼠标自由挥动承担，不必给系统写时间轴；若要接入受控刀路，新增可选字段 `frames`，系统会在存在时优先播放。

## 三、连段推进

- 命中一次，连段 +1，0.95 秒内没有下一次命中就归零。
- 连段上限由段位决定：段位一 2 段、段位二 3 段、段位三 4 段、段位四 5 段。
- 超出 `segs.length` 时停在最后一段。
- 所以一组 `segs` 建议写 3–4 段，第一段接敌、最后一段收势收尾。

## 四、段位与解锁

| 段位 | 熟练度门槛 | 解锁 |
|---|---|---|
| 一 | 0 | 轻击组全部段、连段 2 段 |
| 二 | 10 | **重击组**（右键按住）、连段 3 段 |
| 三 | 26 | 连段 4 段、破势重击可触处决 |
| 四 | 48 | 连段 5 段 |

熟练度来源：普通命中 +1，破势/一闪命中 +3，击杀 +5。跨局不重置（同一会话内累计）。

## 五、输入

| 操作 | 行为 |
|---|---|
| 左键挥动 | 轻击组，按连段取段 |
| 右键按住 + 挥动 | 重击组（需段位二），`moveAction.type` 变 `heavy`，卡肉与慢镜自动升档 |
| 破势时右键挥动 | 处决，段名固定为「处决 · 收刃」，伤害 ×2.6，慢镜走 `finish` 档并推镜 |

## 六、已内置的四武器两套（当前占位值）

| 武器 | 轻击 | 重击 |
|---|---|---|
| 刀 | 缠头刀：日绕山尖 / 浮云起落 / 肋下锥 / 裹脑藏刀 | 倒步劈刀 / 猛虎爬山 / 翻身撩刀 |
| 剑 | 流水十三剑：点腕 / 抹喉 / 挑帘 / 回风 | 断岳三连：劈山 / 崩剑 / 横扫千军 |
| 枪 | 拦拿扎：拦 / 拿 / 扎 / 连环扎 | 回马枪：拖枪诱敌 / 回身崩枪 / 凤凰点头 |
| 棍 | 舞花棍：舞花 / 怀抱琵琶 / 劈棍 | 镇山三棍：麒麟步推棍 / 崩棍 / 扫堂 |

轻击组走「短促、可连续」的路子，重击组走「起手带诱、末段重击」的路子。回马枪特意把「拖枪诱敌」放在第一段，伤害压低、压制也压低，让玩家先卖一个破绽。

## 七、替换方式

1. 只换名字与数值：直接改 `segs` 里对应字段，不需要动任何逻辑。
2. 换整套动作：替换 `light.segs` / `heavy.segs` 数组，保持字段齐全即可。
3. 新增武器：在 `MOVESETS` 里加 key，并让 `Battle.weapons` 同步有这把武器，否则 HUD 会回落到刀。
4. 调段位门槛：改 `PROG.next = [0,10,26,48]`。
5. 调连段窗口：改 `progOnHit` 里的 `PROG.comboUntil = realTime + .95`。
