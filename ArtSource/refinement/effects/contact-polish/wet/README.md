# 湿衣接触滴与纤维候选

本目录为原生静态GLB制作源，由上层 `build_contact_polish.py` 唯一制作入口调用 `build_wet.build(output_dir)`。`build_wet.py` 没有独立制作main，复用项目既有Effect／Layer和GLB发布函数，只向传入候选目录输出。

## 实物与尺寸

`wet_cloth_contact.glb` 为19,448字节、196三角，SHA-256为 `9d8990c4d66c612182763107c757b42bfee0668dbf555b007d1d1c34a11c27af`。根下含8个独立滴mesh `drop_00` 至 `drop_07` 和2个纤维mesh `fiber_00/01`，均有独立变换。

滴的最大外包尺寸为2至3.9毫米；纤维长3.4／3.8毫米、宽0.44／0.38毫米。水滴24三角／滴，平滑外法线；纤维2三角／条。全部资源无动画、骨骼、贴图或扩展。水滴使用普通PBR透明近似，metallic为0、roughness为0.18、alpha为0.56，无自发光。纤维为灰色粗糙PBR。实际透明混合及头显可辨性由Root专项验收。

## 运动与Root接口

`motion.json` 的 `particles` 按节点列出初始局部位置、局部初速度、180至320毫秒寿命和逐项 `opacity_keys`。相邻透明度关键点线性插值，出生前及到达寿命时均为0。

接触坐标基为X实际切向、Z实际外法线、Y为Z叉乘X。初速度由该基转换到Stage，再叠加Stage重力 `(0,−9.81,0)`，重力不跟接触面旋转。锚点先沿真实法线外移8毫米，节点位置随后由初始位移、速度和Stage重力计算。GLB的节点初始translation与运动合同一致，更新时直接覆盖采样位置，避免重复累加初始偏移。

切向由Root从真实刀尖采样提供，当前CombatImpact没有独立tangent字段。独立水滴候选本身不代表真实输入已经接线。只在Root确认的湿衣料接触中选择此层，SOFT_HIT和裸头命中本身不表示湿衣。

## 检查范围

`verify_wet.py` 实际读取已生成GLB，检查8滴／2纤维、独立节点、索引／法线／闭合滴面朝向、2至4毫米尺寸、寿命、透明度关键点和Stage重力。两项正常／边界用例实际通过，输出 `verification.json`。

本目录没有修改app、SDK、正式资源或接触生产逻辑。统一渲染和Root端内消费负责后续接入，当前产物为候选制作资产。
