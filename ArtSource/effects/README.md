# 刀战特效资产

四份原创小型glTF特效用于近身刀战。模型采用米制、+Y向上，每份包含一个普通节点TRS动画，使用标准glTF 2.0材质、顶点RGBA和透明渐边。动画不依赖骨架、纹理、粒子插件或扩展。

| GLB与动画名 | 时长 | 三角面 | 局部坐标与用途 |
| --- | --- | --- | --- |
| `metal_sparks.glb` / `metal_sparks_burst` | 0.24秒 | 36 | XY面、朝+Z，原点为接触位置。18枚长短不一的金属细屑与暖白核心沿不同方向飞散，用于格挡、弹反及敌人护刀接触 |
| `blade_arc.glb` / `blade_arc_cut` | 0.18秒 | 224 | XY面、朝+Z，原点为弧线旋转中心，约0.43m半径。双层窄刃光，首尾渐细，用于明确挥击的短时方向提示 |
| `break_ring.glb` / `break_ring_release` | 0.44秒 | 432 | XZ地面、朝+Y，原点为发力或落脚中心。六段错开金灰色气纹，约0.4m默认半径，用于破势与处决接触 |
| `foot_dust.glb` / `foot_dust_settle` | 0.52秒 | 104 | XZ地面、朝+Y，原点为脚下位置。十片柔边灰尘与六枚微小石屑，用于重落步、受击后撤或倒地接触 |

运行资产位于 `app/src/main/assets/models/effects/`。`effects_manifest.json`提供路径、哈希、默认姿态尺寸及动画名。默认节点姿态是可见的制作峰值，播放从零缩放开始，每个动画在结束时收拢到零。动画中的粒子位移会超出默认姿态包围盒。

## 接线约定

根Entity负责场地位置与方向，动画只影响其内部节点。火星放在实际刀刃接触处，XY平面的法线按接触方向旋转。刀弧应按实际挥刀平面转向并围绕挥动中心定位。气环与尘灰放在石面高度的脚下，模型自身已抬高约0.01–0.02m以留出表面间隙。

每次播放设到0秒，并以表中时长结束显示。反馈按既有事件编号去重，暂停、重开、追踪中断或场景释放时关闭当前显示，恢复时继续消费新事件。高频效果适合复用已加载的实体与播放控制器，场景销毁时统一释放。

特效面积、透明度和发光强度均以局部近身接触为制作尺度。重叠火星与刀光的数量由运行呈现层限制，破势环与尘灰每次事件各播放一份，后续在Space Pro上测量实际渲染开销。

## 生产重建

在仓库根目录运行Blender 4.5 Python，复用项目已有GLB编码器。

```bash
BLENDER=/path/to/Blender
"$BLENDER" --background --factory-startup --python ArtSource/effects/build_effects.py
```

源与运行GLB由同一份几何及动画数据生成。素材为本项目原创，制作脚本使用固定随机种子，重新生产不会改变火星分布。

本轮交付为生产导出的资产与接线约定。按用户要求没有运行测试、设备验收、音画联调或性能测量，普通节点动画在PICO导入后的关联实体与播放效果仍待主控后续验收。
