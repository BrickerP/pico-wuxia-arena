# 酒馆院落细节资产

`courtyard_details.glb`为既有酒馆竞技场增加可直接加载的六个细节模块。运行副本位于 `app/src/main/assets/models/courtyard_details.glb`。

## 加载与空间

按Stage世界原点 `(0,0,0)` 加载，单位为米，+Y向上，-Z为玩家初始前方。新模型中的坐标已经对应当前酒馆位于Stage `(0,0,-4)` 的布局。

中央 `X[-1.35,1.35]、Z[-3.0,0.8]` 保留近身交战净空，装饰集中在两侧。整体宽约6.1m，主要地面范围为 `Z[-4.3,0.4]`。资产不包含运行摄像机、光源或碰撞逻辑。

| 模块 | 主要Stage位置 | 制作细节 |
| --- | --- | --- |
| TeaTable | `(-2.04,0.028,-3.15)` | 分离桌面木板、围牙与线脚、腿足与撑枨、木托盘、青瓷酒杯与小酒壶 |
| Stool | `(-2.02,0.028,-2.42)` | 木质矮凳、腿足横撑和磨损倒角 |
| WineJars | `(2.03,0.028,-3.10)` | 大小酒坛、手拉坯轮廓、翻口与露胎足圈、封口布褶皱、缠颈麻绳与手绑绳结、开口坛内壁 |
| SideRailings | 两侧 `X±2.72` | 石柱脚、木栏、柱帽与横档、嵌钉、双侧挂灯，灯笼复用现有纸面与骨架模型 |
| StoneLotusBasin | `(2.23,0.028,-0.30)` | 分块石砌盆体、压顶倒角、深色水面、带叶脉与缺口的荷叶 |
| SidePaving | 两侧 `X约±2.55` | 与原院落相接的双列石铺地及灰缝基础，支撑两侧家具与栏杆 |

## 几何与材质

当前GLB为6个mesh、27个primitive、29,378三角面、15个材质，文件为6,564,656字节。SHA-256为 `d2bdf0806ef972fe8fc533066aa96830d23c97e7f617ebca26b808c548f53d3e`。

木材、湿石材、五金和纸灯笼沿用已有酒馆资产。酒坛陶釉、青瓷和封口布增加原始512px颜色与粗糙度图，使用固定种子生成釉色流痕、色差和织纹。材质导出为GLB支持的PBR图像，源贴图在本目录的 `courtyard_*_color.png` 和 `courtyard_*_rough.png`。

酒坛采用分段回转曲面与小幅不规则轮廓，杯口、露胎圈、绳结和叶脉保留几何层次。木石边缘使用实际倒角。每个模块合并网格，同时保留材质分区与独立模块根节点。

## 生产源与展示

`build_courtyard_details.py`使用Blender 4.5生成源文件、GLB、贴图和离线展示。它读取同目录的 `tavern_slice.blend` 复用材质和纸灯笼，输出 `courtyard_details.blend` 为可编辑源文件。

```bash
/path/to/Blender --background --factory-startup --python-exit-code 1 --python ArtSource/tavern/build_courtyard_details.py
```

`courtyard_details_preview.png`为离线生产展示，包含现有酒馆与前院铺地。画面中的摄影机、月光和暖光属于制作棚景，运行GLB仅包含新增六模块。当前已生成并导出资产，按用户要求没有运行游戏自测、模拟器操作、验收脚本或终端性能测量。

同源CC0扫描贴图与建筑参考沿用同目录 `README.md` 的来源说明。新增几何、陶釉及布料图由本项目制作。
